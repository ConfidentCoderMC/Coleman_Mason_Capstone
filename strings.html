Strings

A string is a collection of letters, numbers, special characters, and/or whitespace enclosed in between single or double quotation marks.

Useful String Methods

A method is a function that works with data. There are numerous methods that you can use on strings. Here's how you call or request a method:

variable_name.method_name(method arguments go here)


The "." between the variable and method is called the dot operator and tells Python to apply the method to the variable.


Common String Methods:

  • upper() - returns a string in all uppercase
  • lower() - returns a string in all lowercase
  • title() - returns a string wwith the first letter of each word being capitalized
  • strip() - returns a string with all whitespace removed; add "l" or "r" in front of strip to remove left or right whitespace respectively
  • replace(old, new) - replaces all old with new
  • count(item) - returns the number of occurrences of an item

Additional String Tips:

  • You can combine strings end-to-end, a process called concatenation, with the "+" sign.
  • Use the len() function to determine how many characters are in a string. len("Hello") returns 5.
  • You can get a specific character from a string with the index operator ([ ]). Let's say a variable called animal stores the string value "cat". To get the "c" in "cat", use animal[0]. The 0 is the positional value or index of the character in a string.

Note: If you're trying to access the first character in a string, the first item's index is 0. The last character's index is -1.
