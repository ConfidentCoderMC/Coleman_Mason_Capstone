Lists

A list is composed of Python data values enclosed in square brackets, where each item is separated by a comma. Lists are similar to strings in many ways. You can use the len() function to determine how many items are in a list. In addition you can combine lists with the "+" symbol. Lastly, you can use the index operator ([ ]) to access individual items.

If an item in a list is a string or another list, use a second index operator to access the individual characters or elements.

Example:
aList = [3, 67, "cat", [56, 57, "dog"]]
print(aList[2][0])

List Methods

Like strings, lists have a set of methods that make interacting with them possible. Some methods, such as count(), can be used on both strings and lists.

Common List Methods:

  • append(item) - adds item to the end if a list
  • sort() - modifies a list to be sorted
  • reverse() - modifies a list to be in reverse order
  • insert(position, item) - inserts item at position
  • pop() - removes and returns last item; add the optional position argument to remove and return item at position
  • insert(position, item) - inserts item at position

Tuples

Tuples are a special kind of list. The values are usually enclosed in parentheses, and each value is separated by a comma. What makes a tuple unique is its immutable nature. This means the values cannot change. However, it is possible to assign a new value to a variable that represents a tuple.

Note: If you're defining a tuple with only one element, include a trailing comma. Example: my_tuple = (7,)
