Dictionaries

A dicionary allows you to store related data. This data comes in the form of key-value pairs. A key can be used to access the value it's associated with. Here's the basic syntax for creating a dictionary:

dictionary_name = {key : value, key : value, key : value}

Like lists, the values in a dictionary can be of any type (numbers, floats, strings, lists, even other dictionaries!).

Accessing Values in a Dictionary

dictionary_name[key]

Adding Key-Value Pairs

dictionary_name[new_key] = new_value

Modifying Dictionary Values

dictionary_name[key] = new_value

Additional Tips

Use the get(key, value to return if key doesm't exist) method to access a value if it's possible that the key yout're requesting does not exist. The key parameter is required, but the return value is optional. If you don't include this parameter, the method returns None.
